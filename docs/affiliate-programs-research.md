# Affiliate/Partner Program Research

Research pass over 20 coin/bullion dealer affiliate programs, done 2026-08-11. Each entry was checked against
independent sources beyond the original aggregator list — status below reflects what was actually verifiable,
not just what the source list claimed.

**Read this before anything else:** ShareASale shut down on 2026-10-06 and merged into Awin. Any program below
listed as running "via ShareASale" needs to be re-checked on Awin instead — the old ShareASale signup path may
no longer work. This affects BGASC and Cache Metals directly.

**General caution:** most of these programs surface only through third-party aggregator/roundup sites
(getlasso, bestgoldaffiliateprograms, uppromote, etc.), not the merchant's own page, and those sites frequently
disagree with each other on commission and cookie numbers. Treat every figure below as a starting point —
confirm the real terms during the actual application step with each merchant.

## Suggested next step

Before applying anywhere: confirm live status and real terms directly on each merchant's own affiliate page
(linked above), since aggregator sources disagreed with each other repeatedly during this research. Also worth
a deliberate decision on audience fit — most of this list sells bullion (investment-grade metal), while Coin
Collector Companion's audience is numismatic hobbyists filling date/mint-mark gaps in a set. CoinCollecting.com's
Business Partner program is the closest match; APMEX and JM Bullion both carry real numismatic inventory
alongside bullion, so those may work at the edges.
