Owned. accent-100 fill, accent-400 border, accent-200 well, filled gold check, “In collection”.

Missing. neutral-100 fill, neutral-200 well, grey coin at 50%, dashed check.

Pending. The check spins and is disabled. The card stays in its old state until the server confirms. Shown after 150ms.

Failed. Danger border and “!” check. The state rolls back; Retry runs the same toggle again.

Key date. The pill sits top-left, opposite the check. The eyebrow shows the series.

Selected (select mode). The whole card is the hit area, with a 3px accent-700 outline. The check is hidden.

Visitor (someone else’s set). No check, full-strength coin, no gap styling.

Loading skeleton. Same footprint as a real card, with a gentle 1.4s pulse (slower under reduced motion). Render as many skeletons as the expected count, up to 12.

In list rows · pill, 40px tall

The visible label shows the current state; the accessible name states the action (“Mark Odesa Oblast as owned”), with aria-pressed. Ownership is global, so a successful toggle updates every card for that coin and every set’s counts. A failure rolls back and announces “Couldn’t save Odesa Oblast” in a polite live region. Pending appears only if the request takes longer than 150ms, which avoids a flicker on fast responses.

Badges

✓ Owned In this set In 2 sets 1 missing ★ Key date ✓ Complete

22px tall, 12px medium, fully rounded. Every badge carries a word, not only a colour or icon. Owned uses the warm palette, set membership uses neutral surface, missing uses a dashed outline (the same language as the check).

The catalog keeps its sidebar and filters. Rows and cards take the shared name block and add badges for signed-in users only: Owned and In N sets (on a set’s Add-coins sheet, this becomes In this set).

The catalog has no ownership toggle; you change ownership on the coin page or in a set. That keeps browsing calm.

Toasts

Removed Odesa Oblast from this set.
Marked 3 coins as owned.
Couldn’t remove Odesa Oblast.

Bottom-centre, neutral-900 with an accent-200 action. Undo toasts stay for 8 seconds, pause while hovered or focused, and stack to at most one: a new toast replaces the old one and commits it. Focus never moves to a toast. Its action is reachable by keyboard, and its message is announced in the live region. On mobile it sits 12px above the tab bar.
